What “native” means

The gzim executable contains the lexer, parser, semantic analyzer, and runtime. Running gzim app.gzim does not generate a Python file or launch Python behind the scenes. Python is contacted only when code explicitly imports a py.* module or when you run an exported Python file.

One command is the whole toolchain

After installation, gzim doctor confirms the native runtime and platform. You do not need Nim to run programs from a release package.
