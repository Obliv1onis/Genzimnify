Native standard library

These builtins and modules are implemented inside the native runtime. They do not proxy Python packages.

Built-in cooks

NamePurpose
yap(...)Print values separated by spaces.
yap back(prompt)Read one line from standard input.
how many(value)Return the size of text or a collection.
vibes(stop)Create an integer range; also accepts start and step.
add up(values)Sum numeric values.
least / mostFind the minimum or maximum value.
positive(value)Return the absolute value.
ranked(values)Return a sorted stack.
index up(values)Return index/value crews.
link(...values)Zip several collections.
round up(value)Round a numeric value.
unlock(path, mode)Open a native file handle.

Collection methods

Stacks

append, extend, insert, remove, pop, and reverse.

let names be ["amy"]
call up names.append("bob") yo
yap(call up names.pop() yo)

Maps

get, keys, values, items, and pop.

Text

upper, lower, strip, split, replace, startswith, endswith, and join.

math

pull up math
yap(math.pi)
yap(call up math.sqrt(9) yo)

Exports floor, ceil, sqrt, pow, pi, and e.

system

pull up system
yap(system.args)
yap(call up system.cwd() yo)

Exports args, cwd, getenv, and exit. A top-level args stack is also available.

luck

Native random utilities: random(), randint(low, high), and choice(values).

clock and timing

clock.time() returns Unix time. clock.sleep(), timing.sleep(), and timing.run() expose the initial cooperative timing API.

Files

roll with unlock("notes.txt", "w") as file:
    call up file.write("the vibes are saved") yo

File handles provide read, readline, write, and close. roll with always closes the handle.

Local modules

If no native module matches an import, the runtime looks for a corresponding .gzim file. For example, pull up helpers resolves helpers.gzim beside the importing file. Dotted names map to subdirectories.

Deliberately not Python’s standard library

Earlier versions mapped slang module names to Python packages. Native 1.2 only documents modules that are implemented by Genzimnify itself. Unsupported imports fail clearly with NoPullUp.
